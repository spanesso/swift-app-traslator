# Implementation Plan: WhisperKit ASR — Accent-Robust Speech Recognition

**Branch**: `004-whisperkit-asr` | **Date**: 2026-06-02 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/004-whisperkit-asr/spec.md`

---

## Summary

Replace `SFSpeechRecognizer` with WhisperKit (CoreML Whisper large-v3-turbo) to achieve <10% WER on any English regional accent. The existing `AsyncStream<SpeechSegment>` interface is preserved — only the Data layer gains new files. A new `TranslatorState.modelDownloading(progress:)` case surfaces download progress in the UI on first launch. Intel Macs fall back to the existing SFSpeechRecognizer path automatically.

## Architecture Design

### Data Flow — First Launch (model not cached)

```
User presses Record
    │
    ▼
TranscriptionViewModel.toggleRecording()
    │  → TranscribeAudioUseCase.executeBoth()
    ▼
WhisperSpeechListener.start()
    │  → WhisperModelManager.loadModel()
    │      ├─ WhisperKit.download(variant:progressCallback:)
    │      │     fires: downloadProgress: 0.0 → 1.0
    │      └─ WhisperKit(config:) async init
    │
    ├─ downloadProgress stream → DependencyContainer binding
    │     → viewModel.updateDownloadProgress(p)
    │     → translatorState = .modelDownloading(progress: p)
    │     → LiveTranscriptionView shows progress bar overlay
    │
    └─ model ready → AudioStreamTranscriber.startStreamTranscription()
          → SpeechSegment stream → normal pipeline (unchanged)
```

### Data Flow — Subsequent Launches (model cached)

```
User presses Record (within 5 s of launch)
    │
    ▼
WhisperModelManager.loadModel() → loads from disk (~2–4 s)
    ▼
AudioStreamTranscriber starts → SpeechSegment stream
No download progress state shown
```

### Fallback — Intel Mac

```
WhisperModelManager.init() detects hw.optional.arm64 == 0
    │
    ▼
DependencyContainer: usesWhisper = false
    │  uses SpeechRepository(listener: ContinuousSpeechListener)
    │  (ContinuousSpeechListener locale changed to "en")
    ▼
Normal SFSpeechRecognizer path — no WhisperKit code runs
```

### Download Progress Channel (separate from SpeechSegment stream)

```
WhisperModelManager.downloadProgress: AsyncStream<Double>
    │
DependencyContainer.bindDownloadProgress()
    │  for await progress in modelManager.downloadProgress {
    │      await viewModel.updateDownloadProgress(progress)
    │  }
    ▼
TranscriptionViewModel.translatorState = .modelDownloading(progress: p)
    ▼
LiveTranscriptionView — overlay in Spanish pane
```

The download progress stream is entirely separate from `AsyncStream<SpeechSegment>`, preserving clean separation.

```swift
final class WhisperSpeechRepository: SpeechRepositoryProtocol {
    private let listener: WhisperSpeechListener
    init(listener: WhisperSpeechListener) { self.listener = listener }

    }
    func stopTranscription() async { await listener.stop() }
}
```

## Watchdog Design

The watchdog restarts the internal audio pipeline if no segment arrives in 30 seconds, without closing the `AsyncStream`:

```swift
private func scheduleWatchdog() {
    watchdogTask?.cancel()
    watchdogTask = Task { [weak self] in
        try? await Task.sleep(nanoseconds: 30_000_000_000)
        guard !Task.isCancelled else { return }
        await self?.restartAudioPipeline()
    }
}

private func restartAudioPipeline() async {
    // Stop transcriber + audio engine
    // Wait 200 ms
    // Restart audio engine + transcriber
    // Reschedule watchdog
    // continuation stays open — stream not finished
}
```

## Error Handling

| Scenario | Error | UI Response |
|----------|-------|------------|
| Intel Mac | `WhisperASRError.unsupportedHardware` | Silent fallback to SFSpeechRecognizer |
| Network failure during download | `WhisperASRError.downloadFailed` | `.error` state, error banner, retry on next Record press |
| Disk full | `WhisperASRError.downloadFailed` | Same as above + "Check available storage" message |
| CoreML load failure | `WhisperASRError.modelLoadFailed` | `.error` state, error banner |
| Microphone permission denied | (existing path) | `.permissionDenied` state (unchanged) |
